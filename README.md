<h2>Theory:</h2>

<p>
Hill climbing is a variant of Generate and Test algorithm in which feedback from the test procedure is used to help the generator decide which direction to move in the search space.
The feedback is provided in terms of a heuristic function.
</p>

<p>
It is a local search algorithm that continuously improves the current state by selecting a better neighbouring state. The algorithm stops when it reaches the goal state or when no better state can be found.
</p>

<hr>

<h2>Algorithm:</h2>

<ol>

<li>
Evaluate the initial state. If it is a goal state, return it and quit. Otherwise, continue with the initial state as the current state.
</li>

<li>
Loop until a solution is found:
<ul>

<li>
Select an operator and apply it to the current state to generate a new state.
</li>

<li>
Evaluate the new state using the heuristic function.
</li>

<li>
If the new state is a goal state, return the solution and quit.
</li>

<li>
If the new state is better than the current state, replace the current state with the new state.
</li>

<li>
If the new state is not better, continue searching with the current state.
</li>

</ul>
</li>

<li>
Repeat the process until the required goal state is achieved.
</li>

</ol>


<hr>

<h2>Steps Applied:</h2>


<h3>Step-1:</h3>

<p>
Generate a Random String of length equal to the given target string.
</p>


<h3>Step-2:</h3>

<p>
Mutate the randomized string by changing one character at a time.
</p>


<h3>Step-3:</h3>

<p>
Evaluate the fitness function or heuristic function by calculating the ASCII difference between generated string and target string.
</p>


<h3>Step-4:</h3>

<p>
Repeat Step-2 and Step-3 until the fitness score becomes Zero to achieve the Global Minimum.
</p>

<h2>Program:</h2>

```python
import random
import string


def generate_random_solution(answer):
    length = len(answer)
    return [random.choice(string.printable) for _ in range(length)]


def evaluate(solution, answer):

    target = list(answer)
    difference = 0

    for i in range(len(target)):

        current = solution[i]
        expected = target[i]

        # Calculate ASCII difference
        difference += abs(ord(current) - ord(expected))

    return difference



def mutate_solution(solution):

    new_solution = solution.copy()

    index = random.randint(0, len(new_solution)-1)

    new_solution[index] = random.choice(string.printable)

    return new_solution



def SimpleHillClimbing():

    answer = "Artificial Intelligence"

    best = generate_random_solution(answer)

    best_score = evaluate(best, answer)


    while True:

        print("Score:", best_score,
              " Solution:",
              "".join(best))


        if best_score == 0:
            break


        new_solution = mutate_solution(best)

        score = evaluate(new_solution, answer)


        if score < best_score:

            best = new_solution

            best_score = score



SimpleHillClimbing()
```
